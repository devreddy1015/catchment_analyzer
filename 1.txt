HOW TO RUN THE WHOLE PROJECT
============================

Requirements: Python 3.11+ and Node 18+
Run every command from the project root (the folder holding this file).

1. INSTALL (once)
-----------------
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
npm --prefix frontend install

2. RUN (the easy way - starts both servers)
-------------------------------------------
./dev.sh

   Ctrl-C stops both.

3. RUN (manually - two terminals, both at the project root)
-----------------------------------------------------------
# terminal 1 - the API
.venv/bin/uvicorn backend.main:app --reload --port 8000

# terminal 2 - the interface
npm --prefix frontend run dev

4. OR RUN WITH DOCKER (one container, everything on port 8000)
--------------------------------------------------------------
docker compose up --build

5. URLS
-------
Web interface        http://localhost:3000
API                  http://localhost:8000/api/analyzeContour
Interactive docs     http://localhost:8000/docs

6. TRY IT STRAIGHT AWAY
-----------------------
curl -X POST http://localhost:8000/api/analyzeContour \
  -F "file=@contours_1m.kml" \
  -F "rainfall_mm=1150"

curl -X POST http://localhost:8000/api/analyzeArea \
  -H "Content-Type: application/json" \
  -d '{"latitude": 18.52, "longitude": 73.75, "area_km": 5, "rainfall_mm": 700}'

7. TESTS
--------
.venv/bin/python -m pytest
